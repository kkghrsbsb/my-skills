# Research Synthesize

Read [the shared protocol](../../research-flow/protocol.md). State `synthesize`, the requested artifact, and whether the result is a draft, an internal recommendation, or a final deliverable.

Start from the question and audience, then group evidence by claim rather than summarizing sources one at a time. Connect each material factual claim to a source card or an explicit source locator. Mark interpretations as analysis and record user or project choices as decisions. Do not cite material that was not actually read or use a bibliography to imply support it does not provide.

Compare source scope, dates, definitions, methods, and incentives before treating disagreement as a contradiction. Keep meaningful counterevidence and unresolved questions near the affected conclusion. Choose language that matches the evidence: a narrow observation does not establish a universal rule.

Use [the synthesis template](../../research-flow/templates/synthesis.md) for a durable result. Before completion, check the answer against the requested scope, traceability of central claims, important gaps, and delivery state. A branch may draft a bounded section, but the main coordinator decides cross-source conclusions and updates shared state when persistence is in scope.
