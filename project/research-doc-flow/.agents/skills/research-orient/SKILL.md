# Research Orient

Read [the shared protocol](../../research-flow/protocol.md). Start with the user's actual question and intended use, not an exhaustive inventory of every document.

Announce `orient`, whether the pass is read-only, and whether it remains in the main conversation. Inspect only enough project instructions, existing artifacts, source lists, and representative materials to identify where relevant knowledge lives. If a previous `.agents/research-flow/state.md` exists, treat it as a lead and verify important claims against actual materials.

Clarify or propose the smallest useful question. Identify the audience, decision or learning goal, scope and date boundary, what is already known, which sources are accessible, and the most important unknowns. Distinguish an observed fact from an old summary, a source claim, and the user's stated goal.

Return a compact orientation brief: the working question, relevant material map, high-value first sources, likely limitations, and a recommended next activity. Do not create a state file, collect new sources, or edit notes during a read-only orientation unless those actions are in the user's request.
