# Research Tool Connections

This directory holds reproducible access notes for tools actually used in a research project. The template includes [Zotero](zotero.md) as an example based on one local check. A copied note is a starting point; its availability must be rechecked in the target environment.

Use `research-tool-connect` when adding or rechecking a connection. Add one Markdown file per useful integration. Keep each note short:

- Research use and available route (app, local API, connector, or CLI).
- Prerequisites and the smallest read-only status and capability checks.
- Date, environment, observed result, and what was not checked.
- Common failure interpretation and a way to retry.

Record credentials only by their configuration location or access method, never by value. Avoid private profile paths, item lists, and absolute machine paths in files that may be copied back into the shared template. Merge portable methods into this template file by file; retain project-specific observations in the research project.
