# Research Documentation Flow

Use this workflow for project research, source collection, evidence capture, synthesis, or resuming an existing research thread. Read [.agents/research-flow/protocol.md](.agents/research-flow/protocol.md), then load only the relevant skill:

| Need | Skill |
| --- | --- |
| Establish a research question and map existing material | [research-orient](.agents/skills/research-orient/SKILL.md) |
| Turn a source into traceable evidence | [research-capture](.agents/skills/research-capture/SKILL.md) |
| Compare evidence and draft a bounded conclusion | [research-synthesize](.agents/skills/research-synthesize/SKILL.md) |
| Continue after a pause or context change | [research-resume](.agents/skills/research-resume/SKILL.md) |

Treat source claims, analysis, and user decisions as distinct. The main coordinator alone updates `.agents/research-flow/state.md`; branch sessions return evidence instead. Existing source files and observable facts outrank saved summaries.
